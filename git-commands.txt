# Git & GitHub Commands Cheat Sheet

## Initialize Repository
git init
# Initializes empty Git repository

## Check Status
git status
# Shows file status (tracked, untracked, modified)

## Add Files to Staging
git add .
git add <filename>
# Moves files from untracked to staged

## Commit Changes
git commit -m "Your Message"
# Saves staged changes

## Restore Deleted/Modified File
git restore <filename>
# Restores tracked file

# Remote Repository

## Add Remote
git remote add origin https://github.com/username/repository.git

## Check Remote
git remote -v

## Change Remote URL
git remote set-url origin https://ghp_xxxxxxxxxx@github.com/username/repository.git

## Push Code
git push origin master
git push origin main

# Git Config

## Check Username & Email
git config --global user.name
git config --global user.email

## Set Username & Email
git config --global user.name "Your GitHub Username"
git config --global user.email "yourgithub@gmail.com"

## Verify Config
git config --global --list

# Branches

## Show Branches
git branch

## Create Branch
git branch dev

## Switch Branch
git switch dev
git checkout dev

# Logs

## Full Commit History
git log

## One Line History
git log --oneline

# HEAD
# HEAD represents latest commit of current branch

# Push New Branch to GitHub
git switch dev
git status
git push origin dev

# Pull Request (PR)
# PR is used to merge one branch into another on GitHub

## Merge Steps on GitHub
1. Open GitHub Repository
2. Click Pull Requests
3. Click New Pull Request
4. Base = master/main
5. Compare = dev
6. Create Pull Request
7. Merge Pull Request

# Update Local After Merge
git switch master
git switch main

git pull origin master
git pull origin main

# Fetch vs Pull

## Fetch
git fetch
# Downloads all branches and updates from GitHub

## Pull
git pull origin main
# Downloads + merges latest changes into local

# Important Commands Summary

git init        -> Initialize repository
git status      -> Check status
git add         -> Add files to staging
git commit      -> Save changes
git push        -> Upload code to GitHub
git pull        -> Download & merge changes
git fetch       -> Download remote updates
git branch      -> Show/create branches
git switch      -> Switch branches
git log         -> Show commit history
